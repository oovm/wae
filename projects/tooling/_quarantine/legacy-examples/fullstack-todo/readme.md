# fullstack-todo

## 用途

产品验证矩阵条目：见下方覆盖范围。

## 运行

```bash
pnpm --filter @wae-example/fullstack-todo dev
```

## 构建

```bash
pnpm --filter @wae-example/fullstack-todo build
```

## 覆盖

- TSX UI
- @wae/client
- @wae/server
- typed RPC 契约
- 表单
- 服务端数据
- 客户端状态
- 错误处理

## 不覆盖

- Cloudflare DO
- 移动 WebView
