# frontend-ui

## 用途

产品验证矩阵条目：见下方覆盖范围。

## 运行

```bash
pnpm --filter @wae-example/frontend-ui dev
```

## 构建

```bash
pnpm --filter @wae-example/frontend-ui build
```

## 覆盖

- @wae/ui 主题
- Button / Dialog / Form / Tabs / Tooltip / Popover / Toast
- 响应式布局
- 暗色模式

## 不覆盖

- server
- RPC
- WebView native
